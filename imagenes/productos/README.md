# Imágenes de productos

Guarda aquí las imágenes del catálogo. Usa nombres sencillos, por ejemplo `audifonos.jpg` o `laptop.jpg`.

Para mostrar una imagen, agrega el campo `image` al producto correspondiente en `app/models/ProductCatalog.php`, por ejemplo:

```js
image: "imagenes/productos/audifonos.jpg"
```

Si `image` queda vacío, se conserva el recuadro de ejemplo. Utiliza imágenes propias o con permiso de uso.
